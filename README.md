# Tweakly

Правки от клиентов прямо на сайте. Клиент отмечает нужное место и пишет комментарий, а дизайнер получает всё одним сообщением в Telegram.

[Открыть бота](https://t.me/WebTweakly_bot)

## Как это работает

1. Создайте проект в боте
2. Вставьте код на сайт (бот пришлёт инструкцию)
3. Отправьте клиенту защищённую ссылку
4. Получайте правки в Telegram

## Что умеет

- Проекты под каждого клиента
- Защищённые ссылки: новая ссылка отключает старую
- Просмотр и управление всеми правками в боте
- Уведомления в Telegram

## Статус

Бета-версия. Бот бесплатный и без ограничений. Если хочется поддержать проект, есть Pro-подписка.
