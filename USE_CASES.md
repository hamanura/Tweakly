# Сценарии использования Tweakly

Tweakly подходит для ситуаций, когда нужно получить замечания по конкретным местам сайта и не собирать их вручную из разных чатов и скриншотов.

## 1. UX/UI-дизайнер согласовывает сайт с клиентом

**Ситуация:** дизайнер передал клиенту сайт или готовую страницу на проверку. Клиент замечает неточности в отступах, тексте, цветах или расположении элементов.

**Как помогает Tweakly:**

1. Дизайнер создаёт проект и подключает Tweakly к сайту.
2. Отправляет клиенту клиентскую ссылку.
3. Клиент открывает страницу, нажимает на нужное место и описывает замечание.
4. Дизайнер получает уведомление и просматривает комментарии в Telegram.

**Результат:** замечание привязано к месту на странице, поэтому проще понять, что именно нужно изменить.

## 2. Веб-разработчик собирает правки после сдачи страницы

**Ситуация:** заказчик проверяет готовую страницу и находит несколько ошибок или деталей, которые нужно поправить.

**Как помогает Tweakly:**

- заказчик оставляет комментарии непосредственно на странице;
- разработчик получает уведомления в Telegram;
- правки по сайту можно просматривать в рамках отдельного проекта.

**Результат:** меньше необходимости сопоставлять сообщения, скриншоты и описания вручную.

## 3. Фрилансер ведёт несколько клиентских проектов

**Ситуация:** у фрилансера одновременно несколько сайтов на согласовании. В обычной переписке комментарии от разных клиентов легко смешать.

**Как помогает Tweakly:**

1. Для каждого сайта создаётся отдельный проект.
2. Клиент получает ссылку своего проекта.
3. Комментарии поступают в соответствующий проект.
4. Фрилансер открывает нужный проект и просматривает его правки через Telegram-бота.

**Результат:** обратная связь по разным сайтам организована по проектам.

## 4. Небольшая студия согласовывает сайт с заказчиком

**Ситуация:** студия передаёт заказчику страницу на проверку и хочет получать конкретные замечания, а не общие сообщения вроде «внизу что-то съехало».

**Как помогает Tweakly:**

Заказчик отмечает нужную область сайта и пишет, что требуется изменить. Комментарий поступает владельцу проекта в Telegram, где его можно просмотреть и обработать.

**Результат:** команде проще интерпретировать замечания и возвращаться к нужным местам страницы.

## Для кого создан Tweakly

- UX/UI-дизайнеры;
- веб-дизайнеры;
- веб-разработчики;
- фрилансеры;
- небольшие дизайн- и веб-студии.

Tweakly не заменяет общение с клиентом. Он помогает сделать одну конкретную часть этого общения — сбор правок по сайту — более наглядной и организованной.
