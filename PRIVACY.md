# Конфиденциальность

Последнее обновление: 4 ноября 2026 года

Эта страница описывает, какие данные обрабатывает Tweakly в текущей бета-версии и для чего они нужны. По мере развития продукта документ будет обновляться.

## Какие данные обрабатываются

В зависимости от использования Tweakly могут обрабатываться:

- **Данные Telegram:** Telegram ID и username, если он передан Telegram при взаимодействии с ботом.
- **Данные проектов:** информация, которую владелец указывает при создании и настройке проекта, включая данные, необходимые для связи проекта с сайтом.
- **Комментарии:** текст правок и технический контекст, необходимый для привязки комментария к странице и месту на ней.
- **Данные доступа:** сведения, необходимые для работы клиентских и владельческих ссылок проекта.

Если у пользователя Telegram не задан username или Telegram не передал его боту, поле username может оставаться пустым.

## Для чего используются данные

Данные нужны, чтобы:

- создавать и отображать проекты;
- проверять доступ к проектам по защищённым ссылкам;
- показывать комментарии и управлять их статусом;
- связывать комментарии с соответствующими страницами сайта;
- отправлять владельцу проекта уведомления о новых правках через Telegram;
- поддерживать работу и безопасность сервиса.

## Сторонние сервисы

Tweakly использует Telegram для работы бота и доставки уведомлений, а Supabase — для серверной обработки и хранения данных приложения. При использовании этих сервисов данные обрабатываются также в соответствии с условиями и политиками соответствующих провайдеров:

- [Политика конфиденциальности Telegram](https://telegram.org/privacy)
- [Политика конфиденциальности Supabase](https://supabase.com/privacy)

## Ссылки доступа

Ссылки Tweakly предназначены для разграничения доступа клиента и владельца проекта. Не публикуйте владельческую ссылку и передавайте клиенту только клиентскую ссылку.

Если необходимо прекратить действие ранее выданных ссылок, используйте функцию их перевыпуска в Telegram-боте. Перевыпуск отзывает предыдущую активную пару ссылок.

## Хранение и удаление данных

Данные хранятся столько, сколько это необходимо для работы проекта и связанных с ним функций. Точные сроки хранения и порядок удаления данных в текущей бета-версии отдельно не опубликованы.

По вопросам доступа, исправления или удаления данных напишите автору проекта: [@hamanurik](https://t.me/hamanurik). В обращении укажите Telegram-аккаунт и проект, к которому относится запрос. Не отправляйте пароли, секретные ключи или владельческие ссылки.

## Безопасное использование

- Не публикуйте ссылки владельца проекта.
- Отправляйте клиенту только предназначенную для него ссылку.
- Перевыпустите ссылки, если есть подозрение, что они попали к посторонним.
- Не добавляйте в комментарии пароли, платёжные данные и другую конфиденциальную информацию, которая не нужна для описания правки.

## Важное примечание

Tweakly находится в стадии бета-тестирования. Эта страница — описание текущей обработки данных, а не исчерпывающий юридический документ. Перед коммерческим запуском необходимо дополнить её юридическими сведениями об операторе сервиса, применимом законодательстве, правовых основаниях обработки и конкретных сроках хранения.
